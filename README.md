# Reconnaissance Blind Chess AI

An AI agent for playing Reconnaissance Blind Chess (RBC), a chess variant where players have limited information about the opponent’s pieces and board position.

The project explores AI decision-making under uncertainty, combining chess strategy with incomplete-information reasoning.

## Project Structure

The repository contains the implementation developed across four parts, along with an overview document.

## Technologies

- Python
- Chess AI
- Incomplete-information reasoning
